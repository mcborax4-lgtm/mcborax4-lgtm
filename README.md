## Проекты

### Germany Heizung Telegram Bot

Прототип автоматизации первичных ответов пользователям на русском и немецком языках.

- Подбор готовых ответов по ключевым словам.
- База знаний в коде.
- Логирование обращений.

Статистика хранится в памяти и сбрасывается при перезапуске. Проект демонстрирует простую логику обработки обращений.

Репозиторий: https://github.com/mcborax4-lgtm/heizung-bot
